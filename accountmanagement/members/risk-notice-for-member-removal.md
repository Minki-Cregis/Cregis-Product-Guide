# 移除成员风险说明

为了保障您团队资产的安全以及业务流程的连续性，在 Cregis 平台上移除团队成员前，请务必仔细阅读以下风险提示，并完成对应的配置检查与清理工作。

## 资产与钱包安全

* 单签钱包管理权限转移
  * 若被移除成员为某个单签钱包的创建人，将其移除后，团队将<mark style="color:$danger;">**彻底失去**</mark>对该钱包的管理权限。
  * 建议：移除前，请先将该钱包内的资产转移至其他安全的团队钱包中。

## 业务协作与审批流程

* 存在未处理的审批数据
  * 若被移除成员在“协作”模块中仍存在未结清的审批数据，系统将禁止移除该成员。
  * 建议：请先清理、撤销或完成该成员相关的审批流程，再重新执行移除操作。
* 风控策略影响
  * 若被移除成员是某项风控策略的唯一指定审批人或签名人：
    * 移除成员后，该风控策略依然生效
    * 但后续所有命中该策略的交易都将因缺少审批/签名人而无法正常处理。
  * 建议：移除前，请检查风控策略，确保每个策略均配置了可用的替代审批/签名人。

## 系统自动化与风险监控

* 自动化规则中断
  * 若被移除成员正在运行任何“自动化”任务，成员被移除后，对应的自动化任务<mark style="color:$danger;">**将立即停止运行**</mark>。
  * 建议：移除前，请检查自动化任务运行状态，并由其他在职成员重新启动或接管该自动化流程。
* AML 风险警报接收
  * 若被移除成员被设为 AML 收款自动扫描规则的唯一风险警报接收人，系统将禁止移除该成员。
  * 建议：请先为 AML 扫描规则配置另一位风险警报接收人，保存生效后再进行移除操作。

## 通知配置自动关闭风险

* 当被移除成员是以下关键业务通知的唯一接收人时，移除该成员后，系统将<mark style="color:$danger;">**自动关闭**</mark>对应的通知设定，可能导致团队漏收关键业务警报：
  * WaaS 项目通知
    * 回调失败通知
    * 启用 / 禁用项目通知
    * 重置 API Key 通知
    * 团队余额不足以支付服务费用通知
    * 异常支付单通知
  * 支付引擎通知
    * 回调失败通知
    * 启用 / 禁用项目通知
    * 重置 API Key 通知
    * 异常支付单通知
  * 团队账户通知
    * 团队余额不足通知
* 建议：在移除成员前，请逐一检查上述“WaaS 项目”、“支付引擎”以及“团队账户”中的通知设置，重新指定其他成员作为通知接收人，避免因通知关闭引发业务中断或资产风险。
