# 私隐政策及个人资料收集声明

1. **收集目的**

由 Cregis（在本“私隐”部分中称为“本公司”、“我们的”或“我们”）收集、使用及持有的个人资料，可能用于以下目的：(a) 处理您的服务请求、付款指示以及由第三方付款人作出的付款；(b) 处理相关服务；(c) 与您联络；及 (d) 满足相关法律或监管机构的披露要求。



2. **受让人类别**

为达致上述目的，我们可能会将您的全部或部分个人资料披露予第三方（在您所在地区之内或之外），包括但不限于以下第三方：(a) 第三方服务供应商（包括但不限于保险公司、银行、律师、核数师/会计师，以及为我们提供行政、电脑、付款或其他服务以使我们能够营运业务的其他第三方服务供应商或支付机构）；(b) 专业顾问；(c) 监管及政府机构；(d) 执法机构；(e) 审裁处/法院。我们可能会在与另一家公司进行影响我们全部或大部分业务的控制权、管治、结构及/或管理的交易时，或在为满足适用的法律或监管要求而必须的情况下，转移您的个人资料。然而，未经您的同意，我们不会将您的个人资料披露予任何其他第三方作直接促销之用。



3. **未能提供个人资料的后果**

除非我们另有说明，否则您必须提供我们所要求的个人资料。如果未能提供任何该等个人资料，我们可能无法向您提供服务或执行上述第 1 节所述的目的。



4. **查阅及更正权利**

根据香港《个人资料（私隐）条例》（下称“该条例”），您有权要求查阅及更正您向我们提供的任何个人资料。您可透过书面形式电邮至 [official@cregis.com](mailto:official@cregis.com)，向我们的首席信息安全官（Chief Information Security Officer）提出有关要求。根据该条例，我们有权就处理任何查阅个人资料的要求收取合理费用。



5. **删除及清除权利**

如我们持有的个人资料已不再为收集该等资料的原定目的所必需，或您已撤回同意且我们并无其他具优先效力的法律依据继续保留该等资料，您可要求我们删除或清除您的个人资料。我们将根据《个人资料（私隐）条例》（下称“该条例”）及其他适用法律评估您的要求。如法律、法规或监管要求规定或允许我们保留相关资料，或为确立、行使或抗辩法律申索所必需，我们可能会拒绝您的要求或限制删除范围。您可透过书面形式电邮至 [official@cregis.com](mailto:official@cregis.com)，向我们的首席信息安全官（Chief Information Security Officer）提出有关要求。
